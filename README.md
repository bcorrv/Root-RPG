# Root RPG — Sandbox Companion

Companion web/PWA para una campaña sandbox física de **Root**.

## Filosofía
- **Mesa física = mundo**
- **App = memoria y sistema**
- **GPT / GM = interpretación, NPC, consecuencias y lectura del mundo**
