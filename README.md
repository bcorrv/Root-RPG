# Root RPG — Sandbox Companion

Companion web/PWA para una campaña sandbox física de **Root**.

## Filosofía
- **Mesa física = mundo**
- **App = memoria y sistema**
- **GPT / GM = interpretación, NPC, consecuencias y lectura del mundo**

## v0.3 — Button-first
La interfaz fue rediseñada para jugar desde el teléfono sin estar escribiendo.

- El único dato que necesitas escribir al comenzar es tu nombre.
- Acciones mediante botones.
- Movimiento mediante selección de claros 1–12.
- Resolución de riesgo mediante los dos dados físicos de Root y botones 0–3.
- Fase del Mundo guiada por botones.
- Carta de Orden registrada por palo.
- Rumores generados desde la Carta de Orden + lo que realmente hizo el autómata.
- Estados de claros mediante botones.
- Lugares Míticos con descubrimiento y servicios desbloqueables.
- Personaje, XP, mejoras, inventario y reputación.
- Alianza Automatizada activable.
- Bitácora automática.
- Autoguardado local y respaldo JSON.
- PWA instalable desde GitHub Pages.

## Arquitectura
El tablero físico sigue siendo la fuente de verdad territorial. La aplicación no reemplaza piezas, edificios ni movimientos; registra todo lo abstracto que el tablero no puede recordar cómodamente.
